## Zen's Tracker

Schedule, Contents, Expense management app

### Tech Stack

#### FE
React + Typescript + Vite

#### App
React Native

#### BE
Node.js + Express.js

### How to install dependency
```bash
// after cloning . . .
npm install
yarn install
pnpm install 
```

### How to run on local
```bash
npm start
yarn dev
pnpm dev
```

### How to build
```bash
npm run build
yarn build
pnpm build
```
